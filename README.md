# Alemi Finanzas — descargas para Linux

Gestión financiera e inventario para tu taller o negocio.
Creador y Diseñador: **Frank Molina**.

## Instalar

1. Descarga **AlemiFinanzas.flatpak** desde la sección
   [Releases](https://github.com/FrankM03-code/alemi-finanzas-descargas/releases/latest).
2. Ábrelo con doble clic (se abre el Centro de Software) y dale **Instalar**,
   o en una terminal:

   ```
   flatpak install --user AlemiFinanzas.flatpak
   ```

## Actualizaciones

Una vez instalado, Alemi Finanzas recibe las versiones nuevas solo:
aparecen en el **Centro de Software** como cualquier otro programa, o con:

```
flatpak update
```
